如何理解连续获评？

稳定优先按所选年份向前连续入选的已核实年数排序，再比较该年的评级。连续星级、连续必比登单独计算；晋级仍计入连续星级。这个排序是本工具的偏好规则，不是米其林官方排名，也不保证更符合个人口味。

目前已核实完整的 2024、2025、2026 名单。达到已有数据起点的记录显示「至少」，不把早于 2024 的未知记录算成未获评。地区按餐厅官网坐标匹配 URA Master Plan 2025 规划区；历史餐厅的位置和照片若可用，展示的是最近获取的资料，并非当年地址。

菜系大类为本站整理，卡片保留官方英文菜系。街头美食归入「本地 / 东南亚」；融合料理按官方主要菜系分类。$ 为官方相对价格等级，并非实际菜单金额。

本地数据不会自行实时变化。安装更新扩展后，点击「更新当前名单」刷新官网数据；可从历年官方完整名单文章导入更早年份，也可通过 JSON 导入 / 导出备份。新获评不代表新开业，营业状态与订位请查看官方详情。

数据管理

一键更新当前名单

将打开米其林官网标签页，读取名单、照片和完整地址。不会登录 ChatGPT。首次全量更新可能需要几分钟，查询功能可继续使用。

获取之前年份

已内置 2024–2026。更早年份：先找米其林官方的完整年度名单文章，把链接粘贴到下方。程序核对名单总数及分项后才保存；新闻摘要或仅列新餐厅的文章不能作为完整名单。
