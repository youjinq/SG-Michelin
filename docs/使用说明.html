这个程序存在你电脑上，无需 ChatGPT 账号，也没有订阅费。查询、照片和内置历年名单可离线使用；打开官方详情、地图和更新需要联网。

① 先打开使用

双击文件夹内的 打开狮城寻味.cmd，或双击 index.html。请保留整个文件夹，包括 photos 和其他文件。可以把启动文件的快捷方式放到桌面。

② 如何选餐厅

  1. 先选年份，再选西餐、中餐、日餐等菜系。
  2. 用「大区」先选 Central、East 等；选项和下方说明会列出代表地点。再用「地区」选 Orchard、Geylang、Outram / Chinatown vicinity 等英文地区。餐厅卡片也会显示所属大区。
  3. 搜索框可以直接输入餐厅名字、菜系或地址中的街道名称。
  4. 「连续记录」可选连续入选、连续星级或连续必比登。默认「稳定优先」优先显示核实到连续入选的餐厅。
  5. 点「历年评级记录」展开每年的评级；点「地图」查看位置，点爱心加入收藏。

「连续 ≥3 年」表示目前至少核实三年，并不代表餐厅只获评三年。已内置完整 2024、2025、2026 名单。历史名单显示的照片和地址是最近获取的资料，未核实的信息会标注待补全。

③ 一次安装，以后点按钮更新

推荐使用电脑上的 Microsoft Edge 或 Google Chrome。普通 HTML 也能查询，但浏览器限制了本地网页直接读取官网，所以自动更新需要装这个本地扩展。

  1. 在 Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions。
  2. 打开「开发人员模式」。
  3. 点击「加载解压缩的扩展」，选择当前含有 manifest.json 的整个文件夹（原始项目中叫 dist）。
  4. 在浏览器工具栏的拼图按钮里，找到「狮城寻味」，固定它。点击图标就能打开。
  5. 以后进入「更新 / 管理数据」，填官网当前指南年份，再点「更新当前名单」。程序会打开官方标签页，逐页读取完整名单、照片和地址。

更新可能需要几分钟。保持浏览器打开，可以继续查询旧数据。只有完整名单数量核对通过，才保存新名单；更新前自动备份上一份。如果官网要求验证，请自己在官方标签页完成，再回程序点「继续更新」。不要同时用那个官方标签页做其他浏览。

扩展只获准读取 guide.michelin.com 和其照片服务器，不需要 ChatGPT 登录。安装后请保留文件夹原位置；换位置需重新加载。首次安装须由你在自己的浏览器里完成。

④ 获取更早年份

内置的 2024–2026 可以直接切换。若找到米其林官网的完整年度名单文章，在「获取之前年份」填写年份与文章链接，点击获取。程序会核对三星、二星、一星、必比登和入选各项数量。只讲新餐厅的新闻摘要、格式不同的旧文章或 PDF 不能通过这个自动入口；不会把这些不完整资料当成连续获评依据。

更早年份没有统一公开接口，因此无法保证每一年都能自动导入。官网改变结构后也可能需要更新程序；如果更新失败，保留旧数据仍能继续用。

⑤ 保存、备份、迁移

收藏和新增名单保存在当前浏览器。普通 HTML 模式与扩展模式分别保存；如想迁移，先在旧模式「导出 JSON 备份」，再在新模式导入。更新前、换电脑、清除浏览器数据或卸载扩展前，建议导出。

换电脑时复制整个程序文件夹，再导入 JSON。自选照片与更新缓存照片另存在浏览器中，不包含在 JSON；内置 307 张官方照片随 photos 文件夹一起迁移。「添加自己的照片」支持不超过 8MB 的 JPG、PNG 和 WebP。

资料与分类说明

餐厅名单及照片来自 MICHELIN Guide。地区由官方餐厅坐标匹配 URA Master Plan 2025 规划区边界，例如 OUTRAM 显示为「Outram / Chinatown vicinity」；这是规划区，和日常街区叫法未必完全一致。连续排序是本工具的偏好规则，不是米其林官方排名。
