电脑更新，手机查询。

第一次发布

  1. 打开 GitHub 仓库 youjinq/SG-Michelin，上传准备包中的 docs 文件夹与 README.md。不要把压缩包本身作为网站上传。
  2. 到 Settings → Pages，在 Source 选择 Deploy from a branch，选 main 分支、/docs 文件夹，点击 Save。
  3. 等待 GitHub Pages 部署成功，在 Pages 页面点击 Visit site。预期网址为 https://youjinq.github.io/SG-Michelin/；部署前此链接可能打不开。

手机怎么打开

用手机浏览器打开发布的网址，收藏到书签或使用浏览器的“添加到主屏幕”。无需 ChatGPT 登录。名单来自你最后发布的版本；手机照片需要联网加载。手机和电脑的收藏分别保存在各自浏览器。

以后发布新名单

  1. 在电脑上打开「狮城寻味」扩展，先用「更新当前名单」获取新数据。
  2. 更新成功后，点「导出手机版数据」，下载 public-data.json。此文件不含收藏和自选照片。
  3. 在仓库中进入 docs 文件夹，点 Add file → Upload files，上传这个 public-data.json，替换同名文件，再提交更改。
  4. 等 Pages 部署完成后，手机刷新页面。若仍是旧版，关闭页面后重新打开。

普通「导出 JSON 备份」用于个人备份，含收藏。请用专门的「导出手机版数据」按钮发布。
